# Як сфотографувати піцу на телефон, щоб сайт виглядав цілісно

Сайт сам обріже, зменшить і вирівняє кольори фото. Але щоб усі картки виглядали як один набір:

1. **Одне місце й один фон для всіх піц** — та сама темна дошка або дерев’яний стіл.
2. **Денне світло біля вікна**, без спалаху й без жовтих ламп. Знімайте в один день, в один час.
3. **Строго згори** (телефон паралельно столу), піца по центру. Увімкніть сітку в камері.
4. **Піца займає майже весь кадр** — залиште трохи фону по краях (сайт обріже під формат).
5. **Без зуму** — краще підійдіть ближче. Основна камера (1×), не ширококутна.
6. **Без фільтрів і тексту** на фото. Протріть об’єктив :)
7. Найкраще одразу після печі — сир блищить, базилік свіжий.
8. Надсилайте **файлом** (або в Telegram «як файл»), щоб не втратилась якість.
   На iPhone: Налаштування → Камера → Формати → «Найсумісніший» (JPG замість HEIC).

Для блоку про закваску найкраще працюють: бульбашки на тісті великим планом, розріз бортика з порами,
банка із закваскою.
