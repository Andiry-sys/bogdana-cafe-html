Put the client's photos here, named after the slot they replace, then run (in the tools folder):
  npm install   (first time only)
  npm run photos

hero.jpg                 top-down pizza filling the frame (shown in a rotating circle)
pizza-<image>.jpg        one per pizza; <image> = the "image" value in data/menu.js, e.g.
                         pizza-margherita.jpg, pizza-pepperoni.jpg, pizza-bogdana.jpg …
instagram-1.jpg … instagram-6.jpg   Instagram strip (square crop)

Result goes to assets/images/hero | pizza | instagram. Photo tips: docs/client-brief-uk.md
